# DiDistribuidores — Sistema de Gestión y Entrega de Pedidos

## ¿Qué es el sistema?
Es un sistema distribuido para gestionar pedidos de comida a domicilio, permite a los usuarios crear pedidos, procesar un pago simulado y asignar un repartidor.
